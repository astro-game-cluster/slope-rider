金币可以通过跳到它们上面、击败敌人和找到隐藏的方块来收集。超级蘑菇和火焰花等道具可以在问号方块中找到，或通过特殊挑战获得。彻底探索每个关卡以最大化您的收集！

我可以在我的移动设备上玩超级马里奥酷跑吗？
